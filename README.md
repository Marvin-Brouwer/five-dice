### Development

The app lives in [`app/`](/app), and the root scripts delegate to it:

```sh
pnpm install
pnpm dev            # vite dev server
pnpm build          # production build into app/dist
pnpm lint           # tsc --noEmit
pnpm test           # unit tests
pnpm test:e2e       # see app/e2e/readme.md
```

Run `pnpm build` (or `pnpm dev`) once after cloning, before `pnpm lint`.
The router manifest at `app/src/_routes.g.mts` is generated by a Vite plugin
and is deliberately not committed, so a fresh checkout has nothing to typecheck
against until something has built.
