# Accessibility statement

Five dice aims to be usable for everyone. We aim for WCAG 2.1 Level AA compliance: every interactive control is reachable with the keyboard, focus is always visible, contrast ratios are met in both light and dark themes, and the dice and score input use native form controls so screen readers announce them as proper groups.

## Keyboard support

Every page can be operated with Tab, Shift+Tab, Enter, and Space. The score-input radio groups support the standard arrow-key navigation pattern.

As an added bonus, the dice input keyboard supports the number keys.

## Report an issue

If you encounter an accessibility barrier, please <a href="https://github.com/Marvin-Brouwer/five-dice/issues/new" target="_blank" rel="noopener noreferrer">open an issue on GitHub</a>.
